# PayNudge

Automated payment reminders for Xero — get paid faster with SMS & email nudges.

## Tech Stack

- **Frontend**: React + TypeScript + Vite + Tailwind CSS
- **Backend**: Supabase (PostgreSQL, Auth, Edge Functions, Storage)
- **Payments**: Stripe
- **Integrations**: Xero (invoice sync), Gmail (email delivery), Twilio (SMS), Resend (transactional email)

## Getting Started

```bash
npm install
npm run dev
```
